# Humanize Writing (vendored pointer)

Full text lives in the private repo. Cloud copy rule: re-copy the file on updates.

Hard floor (never break): no assistant bleed, no "it is not X, it is Y" antithesis, never output the em dash character, never invent specifics. Vary rhythm, cut performed significance, get specific or cut the claim, put a person in it, trust the reader.

When drafting Cristo copy from scratch: open on the actual subject, write to one person, run the substitution guard (do not replace a removed tell with a colon reveal or a clipped fragment pair).
