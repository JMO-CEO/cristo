# inbox: daily journal drops for the monthly witness

Drop 1 file per day or 1 file per week, your call. Plain markdown or pasted text.

Naming: `YYYY-MM-DD.md` (example: `2026-09-16.md`).

Format per entry (loose):
- Date and place
- What happened with priesthood power that day (2 to 10 lines)
- Optional: mark the sacred candidate with a `WITNESS:` one-liner

Rules:
- Raw is fine. The miner extracts one moment, it never publishes this folder verbatim.
- Never put secrets, passwords, or client confidences here. This folder ships to the public repo.
- Copyrighted text (paintings, hymns, quotes) goes as link plus 1-line note, never full reproduction.
